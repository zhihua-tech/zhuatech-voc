# 主要功能验收矩阵

上海如静知华信息科技有限公司 · https://www.zhuatech.cn/

## 验收目标

客户许可 → 调查审批发布 → 反馈录入 → NPS/满意度统计 → 低分自动回访 → 根因改进 → 效果验收 → 复核结案

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 客户名册 | 用于受邀反馈和回访追踪；不含外部营销发送 | 新建、编辑、查询、详情、导出 |
| 满意度调查 | 发布调查、有效期、低分阈值与回访时限 | 审批发布、结束调查 |
| 客户反馈 | 同客户同问卷单次反馈，提交后锁定 | 确认录入、撤回并停止统计 |
| 回访工单 | 低分反馈自动转回访，分派、处理与复核 | 分派回访、登记回访结果、复核结案、重新处理 |
| 改进行动 | 关联回访根因、责任人与效果验证 | 落实改进、提交改善结果、效果验收 |

## 界面验收

检查业务端模块列表、新建与详情、服务端错误反馈，以及管理端账号权限和审计入口；桌面截图及管理端截图见 README。所有演示金额和人员均为虚构。

## 不宣称已覆盖的事项

一期为企业人员录入受邀客户反馈的 H5 工作台，不包含公开匿名问卷、短信/邮件营销、AI 文本分析或录音。客户撤回停止统计并隐藏当前反馈正文，既有审计保留，不等同于彻底删除全部个人数据。

不将本机测试当成真实生产负载的压力测试，也不声称通过安全合规认证、故障切换或客户现场验收。测试事实见 [测试结果](TEST-RESULTS.md)。

## 增补安全与并发回归

四个不同请求同时修改同一版本，只允许一个成功；五次密码错误后暂时锁定；另一企业的 HTTP 会话无法读到单据、审计或附件；同一秒创建的记录使用数据库顺序号确定先后。
